Deterministic behavior model

OLD GATE: reported clean for files it never read, when the file listing failed, and for a secret that shared a line with a placeholder-shaped string.

NEW GATE: blocks (exit 1) when a secret is found or a present file cannot be read, and fails closed (exit 2) when the file listing is unavailable. A tracked file missing from the working tree is allowed but reported as NOT SCANNED.
